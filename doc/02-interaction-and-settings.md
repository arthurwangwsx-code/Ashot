# 交互与设置设计

## 1. 区域截图交互

启动区域截图后，每个显示器建立一个无边框遮罩窗口，光标所在屏幕优先获得键盘焦点。

交互规则：

- 鼠标按下并拖动：创建矩形选区。
- macOS 三指拖动：即使系统先发送拖动事件而没有普通 `mouseDown`，也以拖动前最后一次光标位置作为选区起点。
- 移动但未拖动：显示十字线和放大镜。
- Space：立即结束遮罩并截取当前最前方的非 Ashot 窗口，行为与 macOS 区域截图切换窗口目标的习惯一致。
- 选区宽或高不超过 3 点：视为取消，避免产生误截图。
- Esc：从任意遮罩窗口取消本次截图。
- 多显示器：每个遮罩只生成自己所在显示器内的 ScreenCaptureKit `sourceRect`。

空格窗口截图不是新的全局快捷键：它只在区域遮罩处于活动状态时生效。触发后应先关闭所有 Ashot 遮罩，再查询并捕获前方窗口；窗口列表必须排除 Ashot 自己的预览、编辑器和遮罩窗口。

三指拖动只在区域截图遮罩已经出现后用于选择区域，不作为全局启动截图的手势。全局拦截会与 macOS 的窗口拖移功能冲突，因此不属于当前设计。

## 2. 预览框定位

### 2.1 设计目标

预览应该靠近刚刚截取的内容，让用户视线和指针不需要跨越整个屏幕，同时不能跑出当前显示器的可见区域。

### 2.2 定位优先级

普通区域和窗口截图把实际截图矩形作为预览锚点。定位候选顺序为：

1. 截图区域右侧。
2. 截图区域左侧。
3. 截图区域下方。
4. 截图区域上方。

预览与截图区域之间保留 12 点间距，与屏幕可见边缘至少保留 12 点间距。

如果四个方向都不能完整容纳预览：

- 将各方向候选位置限制在当前屏幕可见范围内。
- 选择与截图区域重叠面积最小的位置。
- 候选重叠面积相同时，保持右、左、下、上的稳定顺序。

如果截图覆盖当前屏幕 85% 以上，外部空间已经没有实际意义，此时预览改为靠近当前光标，并自动左右换边和限制在屏幕内。全屏和延时全屏截图属于该回退场景。

### 2.3 多显示器规则

- 首先选择与截图锚点相交面积最大的显示器。
- 如果没有有效锚点，使用鼠标所在显示器。
- 最后才回退到主显示器。
- 定位使用 `visibleFrame`，避开菜单栏和 Dock 占用空间。

## 3. 预览行为

- 动画时长为 0.14 秒，初始缩放为 0.98，避免过慢或明显跳变。
- 新预览出现前立即关闭旧预览，任何时刻只保留一个缩略图预览。
- 默认 6 秒自动关闭。
- 光标进入预览时暂停计时，离开后重新计时。
- 预览窗口允许拖动，Esc 或关闭按钮可关闭。

关闭预览只关闭选择界面，不撤销已经完成的自动复制，也不取消已经开始的后台历史写入或自动保存。

## 4. 设置页信息架构

设置页由四个标签组成。

### 4.1 通用

- 权限：显示屏幕录制状态、请求授权、打开系统设置和刷新状态。
- 保存选项：保存目录和 PNG/JPEG/TIFF 格式。
- 截图后操作：
  - 显示缩略图预览。
  - 自动复制到剪贴板。
  - 自动保存到所选文件夹。
- 截图：声音、窗口阴影、Retina 1x、截图时隐藏桌面图标。
- 外观：显示 Dock 图标和应用语言。

### 4.2 历史

- 历史文件目录。
- 历史文件名模板。

### 4.3 快捷键

设置页把两种作用域不同的快捷键分开显示。

全局截图快捷键：

- 点击当前组合后录制新的组合。
- Esc 取消录制。
- 每一项右侧的 × 可以单独禁用。
- 禁止重复组合和 macOS 保留的系统截图组合。
- 使用 Carbon 注册，即使 Ashot 不在前台也能启动截图动作。

编辑工具快捷键：

- 直接录入 A 到 Z 中的一个字母，不使用 Command、Option 或 Control。
- 只在当前激活的 Ashot 编辑窗口内切换工具。
- 文本框或输入法正在输入时不拦截按键。
- 重复字母会显示冲突来源，不覆盖另一项设置。
- 每项可用 × 禁用；禁用状态单独持久化，不会在重启后恢复默认值。
- 全局截图和编辑工具分别恢复默认，互不影响。

默认编辑器键位：

| 工具 | 键 | 工具 | 键 | 工具 | 键 |
| --- | --- | --- | --- | --- | --- |
| 选择 | V | 箭头 | A | 直线 | L |
| 矩形 | R | 椭圆 | O | 画笔 | P |
| 文本 | T | 步骤编号 | N | 模糊 | B |
| 像素化 | M | 高亮 | H | 裁剪 | C |
| 标尺 | U | 取色 | I | OCR | E |

### 4.4 工具

- 取色结果格式。
- OCR 是否移除换行。

## 5. 设置持久化键

| 键 | 类型 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `showPreview` | Bool | true | 是否显示截图预览 |
| `autoCopy` | Bool | true | 是否自动复制 |
| `autoSave` | Bool | false | 是否自动保存 |
| `saveLocation` | String | `~/Desktop` | 保存目录 |
| `imageFormat` | String | `png` | 输出格式 |
| `captureSound` | Bool | true | 截图音效 |
| `windowShadow` | Bool | true | 窗口阴影 |
| `retinaDownscale` | Bool | false | 是否降为 1x |
| `hideDesktopIcons` | Bool | false | 截图期间隐藏桌面图标 |
| `showInDock` | Bool | false | Dock 图标 |
| `appLanguage` | String | `system` | 应用语言 |

全局截图和编辑工具各自使用独立的编码字典与禁用动作集合。不能仅靠删除某一条字典数据表示禁用，否则下次启动会错误恢复默认快捷键。

## 6. 多语言

- 支持跟随系统、简体中文和英文。
- 设置页内容通过 SwiftUI locale 更新，菜单栏和窗口标题通过语言变更通知重建或刷新。
- 新增用户可见文案时必须同时更新 `en.lproj` 和 `zh-Hans.lproj`。
- 动态错误信息可以来自系统，但按钮、标题和固定说明必须本地化。

## 7. 行业约定依据

- Flameshot 的编辑 GUI 使用 `A/R/T/P` 等无修饰字母切换箭头、矩形、文本和画笔，并允许在 Shortcuts 设置中修改。
- CleanShot X 公开记录采用 `R` 矩形、`A` 箭头等编辑快捷键。
- Shottr 的编辑模型强调标注对象可再次选择、移动、缩放和调整属性；Ashot 保留相同的对象化编辑方向。
- Snagit macOS 默认使用 Control 加字母，说明工具语义仍围绕 Arrow、Text、Shape、Blur、Crop、Highlighter 等稳定类别；Ashot按本产品需求简化为编辑器内单字母。
