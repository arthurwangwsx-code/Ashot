# 首次公开发布审核（2026-09-12）

## 评估范围

从仅有初始 Xcode 模板提交的本机工作区审核已有截图应用实现，重点覆盖截图完成链路、文件持久化、滚动捕获的资源边界、分发配置与公开文件检查。这里不是完整安全审计，也不是全部交互场景的验收证明。

| 项目 | 代码状态 |
| --- | --- |

## 本次修复

1. 历史图片异步编码之前预留文件名，避免短时间多次截图重名覆盖；清空历史后到达的旧写入不得恢复条目。
2. 文件名模板移除目录分隔符/控制字符，并限制 UTF-8 长度；元数据改为原子写入。
3. 屏幕捕获增加总像素上限，避免仅限制单边尺寸仍允许过大缓冲区。
4. 窗口预览与屏幕选择统一转换 Quartz/AppKit 全局坐标，避免多显示器 y 轴混用。
5. 滚动截图限制帧数与累计像素，只允许一个在途捕获；停止或换会话后的旧帧被丢弃，捕获时排除本应用窗口。
6. 滚动拼接保持偏移与源帧索引对应，修正 Retina 重叠计算的像素/逻辑单位混用，并限制合成尺寸。
7. 将本机开发签名与公开分发签名分离；发布强制验证版本、工作区、构建、附件、标签和仓库。
8. 修复 ad-hoc 单元测试宿主的启动配置：仅在测试构建关闭 Hardened Runtime，Release 仍保留。修复后本机实际运行 41 项 Swift 测试全部通过。
9. ZIP 改用经过往返校验的打包流程，保留执行权限与符号链接；新增防覆盖、防递归及文件完整性测试。发布前同时验证压缩数据与解压后的应用签名。

## 验证口径

发布脚本只有在离线脚本测试、Swift 单元测试、Universal Release 构建、代码签名校验、DMG 校验与 SHA-256 生成全部成功后，才推送并公开 Release。具体本次实际执行结果以终端记录、产物及 GitHub Release 为准。

尚需人工覆盖的交互：首次授权与重启、真多屏区域/窗口捕获、三指拖动、快捷键冲突、滚动复杂页面、历史目录切换以及不同 macOS 设备的安装行为。当前没有 Developer ID Application 时，只能验证未公证预览路径，不能声称正式公证已通过。

已知维护项：隐藏桌面图标功能仍会修改 Finder 的 CreateDesktop 设置并重启 Finder；应谨慎使用，后续可改为捕获过滤而非修改用户桌面状态。滚动拼接仍为启发式匹配，静态/重复背景可能产生错误拼接；它尚未并入普通截图的预览、历史、自动保存完成链路。历史目录切换的旧条目迁移和完整编辑撤销历史也不在本批发布工程范围。
