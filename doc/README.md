## 当前产品基线

- 形态：macOS 菜单栏截图应用，可选显示 Dock 图标。
- 普通截图：区域、全屏、窗口、3 秒延时和重复上次截图；区域遮罩中按 Space 可快速截取前方窗口。
- 截图后操作：可配置预览、自动复制和自动保存。
- 预览工具：编辑、复制、保存、OCR、钉在屏幕上和关闭。
- 编辑器：选择、箭头、直线、矩形、椭圆、画笔、文本、步骤编号、模糊、像素化、高亮、裁剪、标尺、取色和 OCR；工具支持可自定义的本地字母快捷键。
- 辅助能力：截图历史、滚动截图、取色器、可删除的全局截图快捷键、简体中文和英文。
- 核心系统权限：屏幕录制；滚动截图的全局 Esc 监听可使用辅助功能权限，但界面中的“停止”按钮是无权限回退路径。

## 文档维护规则

- 修改用户可见行为时，至少同步更新功能或交互章节。
- 修改模块边界、数据流、坐标转换、线程或存储策略时，同步更新架构章节。
- 新增回归场景时，同步更新验证与维护章节。
- 自动化通过不等于真实触控板、多显示器、权限弹窗或视觉体验已经验收；这几类证据必须分别记录。
