# 产品与功能设计

## 1. 产品定位

Ashot 是一款轻量 macOS 菜单栏截图工具。基础目标是让用户通过菜单或全局快捷键启动截图，完成选择后立即获得可用结果，并在不中断当前工作的情况下决定是否编辑、复制、保存、识别文字或固定图片。

当前阶段优先保证普通截图闭环：

```text
启动截图 → 选择目标 → 获取图像 → 复制/预览 → 后台写入历史和自动保存
```

不以增加更多截图类型为优先，而以启动可靠、选区自然、结果即时和失败可恢复为标准。

## 2. 用户入口

### 2.1 菜单栏

菜单栏是默认入口，提供：

- 区域截图。
- 全屏截图。
- 窗口截图。
- 3 秒延时截图。
- 滚动截图。
- 重复上次截图。
- 取色器。
- 历史记录。
- 设置和退出。

应用默认采用 accessory 激活策略，不显示 Dock 图标。用户可以在设置中开启 Dock 图标。

### 2.2 全局快捷键

所有主要动作都可以通过全局快捷键执行。快捷键支持重新录制、冲突检查、拒绝 macOS 保留的系统截图组合、单项禁用和恢复默认值。禁用快捷键不会移除菜单命令。

## 3. 截图能力

| 能力 | 当前行为 | 截图后主链路 |
| --- | --- | --- |
| 区域截图 | 多屏遮罩，鼠标或三指拖动选区；空格快速截取前方窗口；Esc 取消 | 复制/预览/历史/自动保存 |
| 全屏截图 | 截取当前主屏幕，可选隐藏桌面图标 | 复制/预览/历史/自动保存 |
| 窗口截图 | 截取前方可捕获窗口，可选添加阴影 | 复制/预览/历史/自动保存 |
| 延时截图 | 等待 3 秒后执行全屏截图 | 复制/预览/历史/自动保存 |
| 重复上次截图 | 重启最近一次截图模式 | 取决于对应截图模式 |
| 滚动截图 | 定时采集主屏幕并拼接重叠区域 | 当前直接进入编辑器 |

滚动截图尚未统一接入普通截图的预览、自动复制、历史和自动保存链路。维护时不能把它视为与普通截图完全等价；若后续统一，应先定义长图预览尺寸、内存上限和失败恢复策略。

## 4. 普通截图完成策略

截图成功后，`CaptureService` 对当次设置做一次快照，然后按以下顺序处理：

1. 更新菜单栏截图反馈。
2. 如果开启自动复制，立即写入系统剪贴板。
3. 如果开启预览，立即显示缩略图预览。
4. 创建不可变图像快照。
5. 后台编码并写入历史目录。
6. 如果开启自动保存，后台编码并写入用户选择的目录。

这条顺序是产品约束：磁盘写入和图像编码不能阻塞剪贴板和预览。自动复制必须在预览出现前完成，以保证截图完成后立即粘贴可用。

默认策略：

| 设置 | 默认值 |
| --- | --- |
| 显示缩略图预览 | 开启 |
| 自动复制到剪贴板 | 开启 |
| 自动保存到所选文件夹 | 关闭 |

## 5. 预览提供的动作

- 编辑：打开独立编辑窗口。
- 复制：将图片写入剪贴板并关闭预览。
- 保存：按当前格式和目录保存，失败时保留预览并显示错误。
- OCR：识别图片中的文字，成功后复制文字；可配置是否移除换行。
- 钉在屏幕上：创建可浮动的图片窗口。
- 关闭：不影响已经完成的自动复制、历史记录或自动保存。

预览会在 6 秒后自动关闭；鼠标悬停时暂停关闭计时。预览窗口可以拖动。

## 6. 编辑器能力

编辑器将原图与非破坏性标注对象分开保存，复制、保存、钉图和美化时再合成最终图片。

| 类别 | 工具 | 行为 |
| --- | --- | --- |
| 选择 | 选择 | 选中、移动、四角缩放和删除标注对象 |
| 线条 | 箭头、直线、画笔 | 指向、连线和自由绘制 |
| 形状 | 矩形、椭圆 | 圈选需要关注的区域 |
| 内容 | 文本、步骤编号 | 添加说明和递增步骤标记 |
| 遮挡/强调 | 模糊、像素化、高亮 | 弱化内容或突出区域 |
| 图像 | 裁剪、标尺、取色、OCR | 调整图片并提取像素或文字信息 |

编辑器能力约束：

- 按住 Shift 绘制箭头或直线时吸附到 45°；绘制矩形或椭圆时约束为正方形或正圆。
- 工具切换使用编辑器本地单字母快捷键，不需要 Command、Option 或 Control。
- 快捷键只在当前编辑窗口生效，不注册为系统全局热键。
- 文本输入和输入法组合期间不拦截字母，避免把正文误识别为工具切换。
- 模糊和像素化属于视觉遮挡，不应被视为不可逆的安全擦除。

默认快捷键遵循截图编辑器常见语义，例如 `V` 选择、`A` 箭头、`R` 矩形、`T` 文本；全部键位都可以在“设置 → 快捷键 → 编辑工具快捷键”中修改或禁用。

## 7. 历史与文件输出

- 每次普通截图都会异步写入内部历史目录。
- 历史元数据记录文件名、日期、来源和逻辑尺寸。
- 默认最多保留 200 条，超出后删除最旧图片。
- 自动保存与历史记录相互独立；自动保存失败时，已经成功的历史记录不应被撤销。
- 输出格式支持 PNG、JPEG 和 TIFF，文件名冲突时追加数字后缀，避免覆盖现有文件。

## 8. 权限与恢复

### 8.1 屏幕录制

区域、全屏、窗口、延时和滚动截图均依赖 macOS 屏幕录制权限。

- 首次启动可以主动请求权限。
- 每次截图前再次检查权限。
- 未授权时显示恢复提示，并可跳转到系统设置。
- 设置页显示当前授权状态，在应用重新获得焦点时刷新。

为了减少重复构建后的权限变化，开发构建应保持稳定的 Bundle Identifier、代码签名团队和应用路径。macOS 最终是否沿用授权由系统隐私数据库决定，不能由应用自行保证。

### 8.2 辅助功能

普通区域截图的三指拖动依赖用户已经在 macOS 中启用“三指拖移”，Ashot 只兼容其产生的拖动事件，不全局拦截该手势。滚动截图使用全局 Esc 时可能需要辅助功能权限，但始终提供可点击的停止按钮作为回退。

### 8.3 稳定性与失败隔离

- 区域选择只允许一个活动会话；再次触发会先取消旧遮罩、键盘监听和光标状态。
- 事件产生的选区在交给 ScreenCaptureKit 前必须校验有限数值、显示器边界、最小尺寸和最大像素尺寸。
- 截图尺寸或屏幕状态无效时应结束本次动作并显示可恢复错误，不能继续申请异常大小的图像缓冲区。
- 截图后的磁盘失败与主截图结果隔离，不能让已经复制或预览成功的截图变成应用级失败。
- 不使用强制取值处理可为空的文件目录或自由绘制点列。

## 9. 当前边界

- 真实屏幕录制授权、全局快捷键、三指拖动、多显示器视觉位置和预览体感不能仅靠无界面单元测试证明。
- 全屏截图没有“截图区域之外”的空间，预览会退化到操作位置附近并限制在可见屏幕内。
- 窗口截图以及区域遮罩中的空格快照当前选择 ScreenCaptureKit 返回列表中的第一个非 Ashot 前台窗口，不包含悬停高亮式窗口选择器。
- 滚动截图仍是独立完成链路。
- 历史写入和自动保存异步执行，因此预览出现时磁盘文件可能尚未完成写入。
- 标注移动、缩放和样式调整尚未形成完整的命令历史；当前撤销/重做主要覆盖标注对象的添加和删除。
